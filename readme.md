# 桌布產生器

黑底桌布（尺寸下拉：預設主螢幕，多螢幕另有橫跨總尺寸，可選常用或自打寬x高）：疊上文字＋多張小圖，一鍵設為 Windows 桌布。

## 需求

- Python 3（Windows，雙擊 `app.pyw` 不跳黑窗）
- `pip install PySimpleGUI Pillow tkinterdnd2`（tkinterdnd2 給檔案總管拖入用，不裝也能跑，只少拖放）

## 使用

```bash
python app.pyw
```

1. 工具列輸入文字、挑顏色（作用在文字清單選中的那組）；「文字+」新增一組（繼承字級／顏色）、「文字-」刪除選中組（可全刪），清單選取切換編輯對象；小圖按「加入」（可多選）或從檔案總管拖圖片進視窗（可多個），清單選取後按「移除」刪除；「複製」把選中的文字或小圖複一份（偏移一點並自動選中副本）；白底 JPG（如 G/O/Y）選中後按「去白底」吃掉連通背景白（框線圍住的白如眼睛不受影響，有✓表開啟中）。
2. 第二列滑桿調字級、文字透明度、文字旋轉（作用在選中的那組文字）；小圖的透明／縮放／旋轉作用在清單選中的那張。
3. 預覽圖可直接拖曳（點中小圖／文字選它拖它並自動選中，點空處清除選中框）；選中的小圖描淡黃框、選中的文字描淡綠框（只在預覽）。
4. 塗鴉：按「塗鴉」開筆（顏色共用文字色、筆寬固定），預覽上直接畫；「復原」收回一筆、「清空」全刪（會確認）；「塗鴉轉圖層」整張存成新圖層，或右鍵拖矩形框選塗鴉區、放開即裁存新圖層（框太小就取消）。
5. 「下載桌布」存 PNG，「設為桌布」直接套用（存到 `Pictures\wallpaper.png`）。

## 檔案

- `app.pyw`：主程式（單檔）
- `settings.json`：自動記住的設定（多組文字／顏色／小圖／位置／滑桿值），關閉或存檔時寫入（舊版單組文字設定會自動轉成第一組）
